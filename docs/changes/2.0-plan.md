## Auftragsköpfe (Kurzform)

### 022 – Kalender-Abo (4a) · S · Sonnet

Supabase Edge Function `ics` liefert einen Kalender mit allen kritischen Aufgaben und den fünf Gates, je Person gefiltert (`?person=S|A`). Zugriff über ein Geheimnis in `settings` (`ics_token`), neu erzeugbar per Button in den Rahmendaten; der alte Link stirbt dann. Kein Login, kein Schreiben. Termine ganztägig, Titel mit Präfix „Spatzlbau:", Beschreibung = Link zur Akte. Anleitung im Rahmendaten-Bereich: „In Kalender abonnieren" (iOS, Google, Outlook). Google aktualisiert bis 24 h – steht im Hinweis. AC: Abo in iOS-Kalender zeigt `kuend-s` am 05.10.; Token neu erzeugen macht den alten Link zu 404; Edge Function ohne Token 401.

### 021 – Phasenstreifen und Gate-Moment (4o, 4p) · M · Sonnet

Kopf: fünf Segmente statt Prozentzahl, Breite = Aufgabenzahl, Füllung = erledigt, Tipp wählt die Phase (ersetzt Phasen-Tabs; Timeline-Filter 019 nutzt dasselbe). Kurznamen aus `settings.phases.short`. Gate-Moment: beim letzten Häkchen einer Phase ganzseitige, ruhige Bestätigung – was geschafft, was als Nächstes; pro Person einmal (`allowlist.seen_gates` jsonb). Rot/Gelb-Regel gilt, keine Konfetti. AC: Segmentbreiten summieren auf 100 %, Gate-Moment erscheint genau einmal je Person je Phase, Realtime beim anderen Gerät ohne Moment.

### 023 – Wochenbrief (4d) · S–M · Entscheidung nötig

Sonntag 08:00 (vor dem Wochencheck) eine Mail je Person: fällig diese Woche, wartet auf dich, neue Kommentare, was Claude geliefert hat. Zwei Wege:
- **A GitHub Action** (wie das Backup): Workflow mit Cron, `scripts/wochenbrief.mjs` liest per Service-Role, versendet über einen Mail-Dienst (Resend, ein API-Key als Repository Secret). Im Repo, unabhängig von Claude. Aufwand M.
- **B Claude Scheduled Task**: Claude liest per Supabase-Connector und schickt über Gmail. Kein Code, keine neuen Secrets, heute einrichtbar. Hängt an Claude und deinem Gmail. Aufwand S.
Empfehlung: **B jetzt, A nie** – zwei Empfänger, drei Monate Laufzeit; ein Mail-Dienst im Repo ist Infrastruktur für ein Ritual, das am 15.01. endet. Wenn B, ist es kein Auftrag an Claude Code, sondern ein Scheduled Task, den ich anlege.

### 025 – Übergabe-Assistent (4f) mit Belegen (4c) · L · Opus

Raum für Raum durch eine Wohnung: Fotos, Mängel, Zählerstände mit Zählernummer, Schlüsselanzahl, Unterschriften-Feld. Ergebnis: PDF mit Zeitstempel in Supabase Storage (privater Bucket, RLS über allowlist), verknüpft mit `uebergabe-s`/`uebergabe-a`/`uebergabe-neu`, plus Kostenzeile „Kaution" auf `faellig`. Offline: Eingaben in IndexedDB, Fotos lokal, Sync bei Netz – dreimal gebraucht, in leeren Wohnungen. Belege allgemein (Foto/PDF an jede Aufgabe) kommen mit demselben Bucket. Ersetzt Backlog „Übergabeprotokoll in der App". Vorarbeit: Einzugsprotokolle (Drive) als Vergleich hinterlegen. Termin: fertig und getestet bis 15.12., Testlauf in einer der Altwohnungen.
